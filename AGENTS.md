# Agent Instructions

- Run `npm test` before committing to ensure lint fixes and basic checks pass.
- Use `rg` (ripgrep) for searching through the codebase.
- Do **not** modify third‑party libraries such as `script/jquery-3.7.1.min.js`.
- Follow existing coding patterns and ES module style within `script/` files.
- Handlebars templates live in `template/`; keep markup structure consistent.
