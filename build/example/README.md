# Example Data

This folder provides generic example documents you can import or mirror when building new content for Dark Heresy 2E.

- `actors/` contains a sample acolyte and NPC actor.
- `items/` contains a sample weapon and gear item.
- `journals/`, `macros/`, `rolltables/`, and `scenes/` provide minimal examples for other Foundry document types.

These examples are intentionally generic and lightweight so they can be safely copied and customized.
